# Break UI · Estrategia y Calidad (F, ola 1)

- **Desbordes en tabla de acciones:** Contenedores con `min-w-0` y scroll horizontal delimitado para evitar que inputs numéricos o títulos largos desborden la cuadrícula del plan.
- **Propuesta Markdown:** Contenedor de visualización de Markdown con `overflow-x-auto` para tablas anchas generadas en el texto de propuesta.
- **Textos extremos:** Textos de justificación largos en acciones no rompen la alineación de las filas.
