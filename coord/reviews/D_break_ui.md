# Break UI · Resiliencia de componentes (D)

- Nombre de proyecto largo (>60 caracteres): texto truncado con elipsis y tooltip con el nombre completo.
- Cifras extremas (ej. 1.234.567 € o porcentajes con decimales): mono tabular evita desplazamientos de layout.
- 12 marcas en selector de color: paleta semántica asigna colores estables a proyecto y líder, neutros con rotación para el resto.
- Modo oscuro y claro: verificación completa sin inversión incorrecta de contrastes.
